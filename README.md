# muchavibra

Marketplace de DJs y clientes para bodas, cumpleaños, fiestas y clubs. Versión de prueba en desarrollo.

- [`web/`](web/README.md): web y API. Cómo arrancarla en local, páginas, API y limitaciones conocidas.
- [`BRAND_GUIDELINES.md`](BRAND_GUIDELINES.md): guía de marca y producto (decisiones confirmadas, propuestas y pendientes).
- [`CLAUDE.md`](CLAUDE.md): instrucciones para trabajar en el repositorio.
- `referencia imagenes/`: capturas de referencia visual. Las fotos que aparecen en ellas son solo inspiración.

## Arranque rápido

```bash
cd web
npm install
npm run dev
```

Abre http://localhost:5173.
